When I saw the three options, I asked myself which one actually mattered to me right now. I'm a student. I'm literally living the problem. So I picked the study productivity tool. The name "Studuo" was the 7th one I came up with, but it stuck.
I started with a basic HTML skeleton and built section by section. I styled each part as I went because that's just how I work.  I need to see it coming together or I lose motivation. The structure felt natural once I had the Glide inspo in my head: nav, hero, features, testimonials, CTA, footer.
The hamburger menu gave me the most trouble. I went back and forth on whether to use JavaScript or try a pure CSS solution. The hero section was also tricky, I wanted it to look captivating using actual images. Getting the colors to not clash took some trial and error too. For icons, I couldn't be bothered downloading SVG packs with my internet situation, so I just used emojis. It actually looks clean.
I used Flexbox for layout, semantic HTML for structure, and media queries for responsiveness. Keeping everything in one file initially helped me move fast before I split it out.
What started as just a task has become something I'd actually want to keep building. Next time I'd add a dark mode toggle, a scroll-to-top button, smooth scrolling, and maybe a working feedback form so it feels like a real product.
